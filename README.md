# KANT 스위치 구성기

칸트라이팅 고객용 스위치 구성·견적 요청 툴. **고객에게 공개되는 페이지입니다.**

**주소** — https://jjiya1225-tech.github.io/KANT-SWITCH/

아임웹에서 이 주소로 외부링크를 겁니다.

## 이 저장소에 넣지 말 것

- **업체가·입고가.** 이 페이지는 고객이 봅니다. 가격은 소비자가(온라인가)만 들어갑니다.
- **직원용 툴.** 직원용은 별도 저장소(`KANT_SMART_TOOLS`)에 있습니다.
  두 개를 한 저장소에 두면 고객이 주소를 고쳐서 직원용 툴에 들어갈 수 있습니다.
- **거래처·단가표·인증키가 담긴 파일.** 공개 저장소입니다.

## 수정하려면

`index.html` 을 직접 고치지 마세요. `part1~5.html` 조각을 이어 붙인 결과물입니다.

```
~/Desktop/Claude/Switch/       ← 작업 폴더
  소스/part1~5.html            ← 여기서 수정
  ./build.sh                   ← 빌드
  cd 테스트 && node regress.js && node smoke.js && node shotFIN.js …
```

빌드·검증이 끝나면 결과물을 이 저장소의 `index.html` 로 복사하고 커밋합니다.

규칙과 함정은 작업 폴더의 `CLAUDE.md`, 전체 배경은
`>_인수인계/인수인계_스위치_구성기.md` 를 보세요.
